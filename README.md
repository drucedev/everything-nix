# everything-nix

Nix system configuration for three machines:

- [Thor](docs/thor.md) — NixOS desktop, x86_64-linux
- [Ivaldi](docs/ivaldi.md) — NixOS home server, x86_64-linux
- [Odin](docs/odin.md) — macOS with nix-darwin, x86_64-darwin

Dotfiles are not managed here. They live in a separate GNU stow repository.
